# Routing Rule

This repository contains a Go project that implements routing rules using the [Fiber](https://gofiber.io/) web framework.

## About

The project demonstrates how to set up and manage routing rules in a META5.It is designed for high performance and easy scalability.

## Prerequisites

- Go 1.18 or higher
- [Fiber](https://gofiber.io/) framework

## Installation

1. Clone the repository:
    ```bash
    git clone https://github.com/your-username/routing_rule.git
    cd routing_rule
    ```

2. Install dependencies:
    ```bash
    go mod tidy
    ```

## Running the Project

Start the server with:

```bash
go run main.go
```

The application will start on `http://localhost:3000` by default.
